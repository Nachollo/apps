# Auditoría de proyecto — ReservIA

**Fecha:** 20/09/2026  
**Evidencia revisada:** `ReservIA_Dashboard_Standalone.html` y artefactos ReservIA disponibles en Library.

## Estado provisional

**PROTOTIPO / DEMO — interfaz convincente, backend no acreditado.**

## Evidencia positiva

- Existe un dashboard navegable con módulos de negocio, reservas, agentes, canales, widget, automatizaciones, analítica, academia y branding.
- La interfaz permite crear visualmente una cuenta piloto, añadir reservas y generar un snippet de widget.
- Existe soporte PWA básico mediante registro de `service-worker.js`.
- El diseño y la arquitectura de producto están mucho más avanzados que una mera maqueta estática.

## Bloqueos

### 1. El propio chat declara que es una demo local

El código inserta literalmente la respuesta:

`Esta pantalla funciona en modo demostración local.`

### 2. Las reservas no acreditan persistencia real

`saveBooking` inserta una fila directamente en el DOM mediante `insertAdjacentHTML`. No se localiza en este standalone una llamada de red que persista la reserva.

### 3. El alta de negocio es visual/local

`createBusiness` crea un elemento `option` en el selector y muestra `Cuenta piloto creada`. No acredita creación de cuenta en backend.

### 4. Chat/agente IA simulado

La respuesta del agente se introduce mediante `setTimeout` y texto fijo. No se acredita llamada a un modelo de IA.

### 5. Integraciones principales no acreditadas en el artefacto

En el HTML standalone revisado no se localizan coincidencias exactas de `fetch(`, `localStorage`, `Stripe` o `Supabase`.

Esto solo demuestra que **este artefacto standalone** no contiene dichas integraciones; no prueba que no existan en otro código fuente no disponible.

## Conclusión

ReservIA **no es paja de diseño**: existe una experiencia de producto bastante completa y navegable. Pero el artefacto disponible está construido expresamente como demostración local. Antes de llamarlo SaaS funcional faltan, como mínimo, backend, persistencia de reservas, autenticación, calendario real, canales reales, IA real y pruebas end-to-end.
